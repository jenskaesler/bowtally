# Security Policy

## Unterstützte Versionen

Sicherheitskorrekturen werden ausschließlich für die jeweils aktuelle Version bereitgestellt.

| Version | Support |
|---|---|
| aktuell (latest) | Ja |
| älter | Nein |

## Sicherheitslücke melden

Sicherheitslücken bitte **nicht** als öffentliches GitHub-Issue melden.

Stattdessen: E-Mail an [mail@jens-kaesler.de](mailto:mail@jens-kaesler.de) mit:

- Beschreibung der Lücke
- Schritte zur Reproduktion
- Mögliche Auswirkung

Eine Bestätigung erfolgt innerhalb von 72 Stunden. Nach Behebung wird die Lücke im
CHANGELOG dokumentiert.
